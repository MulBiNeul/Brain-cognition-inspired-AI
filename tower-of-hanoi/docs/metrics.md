# 지표 정의

문제 p의 라운드 r에서 실제로 채점한 제출 수를 n(p,r), 지속적 오류 제출 수를 E(p,r), 전체 오답 제출 수를 W(p,r)로 둔다. 값은 JSON에서 0–1 비율, 표에서 백분율로 표현한다.

- **Round PER(p,r)** = 100 × E(p,r) / n(p,r), r ∈ {2,3,4,5}.
- **Problem MPE(p)** = 진행한 R2–R5의 PER 합 / 해당 라운드 수.
- **Total MPE** = 계산 가능한 문제의 MPE 합 / 해당 문제 수.
- **유형별 MPE** = 해당 유형에서 계산 가능한 문제의 MPE 합 / 해당 문제 수.
- **Round Error(p,r)** = 100 × W(p,r) / n(p,r), r ∈ {1,2,3,4,5}.
- **Problem Error(p)** = 진행한 R1–R5의 Error 합 / 해당 라운드 수.
- **Total/유형별 Error** = 해당 문제의 Problem Error 합 / 해당 문제 수.

라운드는 n>0이면 포함한다. T 소진으로 끝난 라운드와 진행 중 채점된 제출도 포함한다. 아직 진행하지 않은 라운드, 채점하지 않은 생성 중단은 분모에 넣지 않는다. R1만 진행한 문제는 MPE에서는 제외하고 Error에는 포함한다. N은 MPE 계산에 포함된 문제 수이며 전체 예정 수와 함께 표시한다. 모델 300문제 설정에서는 유형별 N/100, 전체 N/300이다. 사람 10문제 설정에서는 유형별 N/4·N/3·N/3, 전체 N/10이다.

지속적 오류는 R2 이후 **현재 라운드의 추가 이동 제한을 하나 이상 위반한 제출**이다. 제출당 최대 1회이며, 목표 기둥 불일치나 직전 라운드의 성공 여부는 이 판정을 결정하지 않는다. 기본 하노이 이동이 가능한 동안 경로를 추적하며 첫 기본 이동 오류에서 멈추고, 그 오류 이동에서 식별 가능한 추가 제한 위반까지 포함한다.

소요시간은 실제 API 요청에서 기록한 경과시간을 합산한다. 비용은 공급자가 반환한 사용량과 적용 단가로 계산하며, 부분 응답으로 최종 사용량이 누락되면 완전한 비용이라고 간주하지 않는다. 모델 조회 기반 사전 인증은 실험 제출·라운드·MPE에 포함하지 않는다.

사람 평가에도 같은 PER/MPE·오답률 공식을 적용한다. 이동 계획을 작성하거나 취소한 클릭은 제출이 아니며, 전체 계획을 제출해 채점한 경우만 n에 포함한다. 사람의 소요시간은 초기 배치를 제시한 뒤 계획을 제출하기까지의 기록 시간이며 API 요청 시간과 동일한 양이 아니다. 사람 평가에는 API 비용이 없다.
