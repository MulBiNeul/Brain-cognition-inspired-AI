# SameGame 작업 지침

- 사용자가 요청할 때만 Git 커밋·스테이징·푸시를 수행한다.
- **지속 오류 판정과 PER/MPE 집계는 변경 전에 반드시 사용자에게 구체적인 변경안을 설명하고 명시적으로 확인받는다.** 문제 난도·피드백·UI 변경 요청은 지표 변경을 허용하지 않는다.
- 보호할 현재 정의: 현재 문자열에서 기본 조작이 유효하고, 더 지울 묶음이 없고, 실제 최종 문자열을 정확히 제출했으며, 직전 라운드의 금지 규칙을 준수했지만 현재는 오답인 경우만 지속 오류다. 직전 목표는 사용하지 않는다.
- 현재 정답은 직전 규칙 준수 여부와 관계없이 지속 오류가 아니다. 무효 답안과 R1은 지속 오류에서 제외한다.
- 라운드 PER의 분모는 최대 시도 횟수 T다. 문제별 MPE는 제출이 있는 R2 이상 라운드 PER의 평균이고, 전체 MPE는 집계 가능한 문제별 MPE의 평균이다. 미진입 라운드는 제외하고 관측 범위를 함께 보고한다.
- 피드백에 표시하는 위치 수와 내부 채점에 사용하는 위반 목록을 분리한다. 참가자에게 첫 위치만 알려줘도 전체 위반 목록과 현재·직전 규칙 판정은 유지한다.
- 실험 조건별로 문제 데이터·실행 설정·결과 폴더를 구분하고 동일한 채점·집계 코드를 사용한다. 진행 중이거나 완료된 실행의 기록을 덮어쓰지 않는다.
- `tests/test_metric_contract.py`의 보호 기준은 사용자 승인을 받은 지표 변경 시에만 갱신한다.
